# Node JS v20.18 Installation through [tools_installer](./tools_installer.bat)
- If you already have Node JS installed on your machine then please consent with [Shubham Bhale.](https://github.com/shubham-8551) or ask on [Slack](https://arc-i-tech-workspace.slack.com) on the **#help-needed** channel.

1. For online installation script downloads **Node JS v20.18** from the internet.
2. For offline execution already available Node JS from '\Tools\' directory is used.

## Installation steps for script [tools_installer](./tools_installer.bat)
1. The script will call **Node JS installer**
![image](https://github.com/user-attachments/assets/8d16374a-7e7f-4cd9-944e-028df260169e)

2. Accept **License** and click **Next**
![image](https://github.com/user-attachments/assets/d1465b64-6a14-4dd3-adc2-3a0d65111bf1)

3. Click **Next** after folder selection.
![image](https://github.com/user-attachments/assets/e32ae962-1748-4d99-a3b6-afb217a86282)

4. Select **Node.js runtime** and click **Next**.
![image](https://github.com/user-attachments/assets/0dcbd301-81ff-48bc-b3ad-62d19e4da8d9)

5. Do not select checkbox for _Automatically install the necessary tools_. Click **Next**.
![image](https://github.com/user-attachments/assets/af4c5478-e1df-49b1-a38a-701f6d6738b0)

6. Click **Install** installation will start.
   
7. Click on **Finish** to close setup.
![image](https://github.com/user-attachments/assets/5737865c-4436-41b9-8396-0cecbe4df3ba)

9. Installation is done successfully. If any difficulties contact or ask for help [Ajay G.](https://github.com/ajayg2808)(https://github.com/ajayg2808) or [Ajay Deshmukh](https://github.com/ajstyle2410) or ask for help on [Slack](https://arc-i-tech-workspace.slack.com) on the **#help-needed** channel.
